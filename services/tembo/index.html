Marketly

E-commerce marketplace case study

About the client:

Marketly is a demo marketplace showcasing a full e-commerce flow: product catalog, category filters, product cards, cart, and user account area.

What we did:

We built the frontend and backend for an online store experience: product listing with search and filters, cart interactions, checkout flow, authentication modal, and a profile section with orders history.

Results:

The result is a complete, production-style demo of a marketplace with a clean UI and realistic user journeys — from browsing products to payment and tracking orders.

  • Catalog with search, categories, and sorting
  • Cart, checkout, and mock payment flow
  • Profile & orders with editable user data

Tech Stack:

  • Python
  • React
  • PostgreSQL
  • Redis
