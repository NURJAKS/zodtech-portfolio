# Структура проекта zodtech

## Описание

Этот проект представляет собой статический сайт, созданный на платформе Framer и скачанный через Website Downloader Chrome Extension.

## Файловая структура

### Основные HTML файлы

- **index.html** - Главная страница сайта (2.8 MB)
- **case-study.html** - Страница со списком кейсов (8.4 MB)

### Папка case-study/

Содержит отдельные страницы кейсов клиентов:
- bolt.html (14 MB)
- clickup.html (3.0 MB)
- contra.html (2.9 MB)
- framer.html (2.8 MB)
- krea.html (2.9 MB)
- listenlabs.html (2.6 MB)
- magicpath.html (3.0 MB)
- tembo.html (2.9 MB)
- urpal.html (2.8 MB)
- vibecode.html (2.8 MB)
- whop.html (3.0 MB)
- wonder.html (2.9 MB)

### Вспомогательные папки

- **css/** - Для будущих CSS файлов (если будут извлечены)
- **js/** - Для будущих JavaScript файлов (если будут извлечены)
- **assets/images/** - Для изображений
- **assets/fonts/** - Для шрифтов

## Особенности

### Технические детали

1. **Framer Framework**: Сайт использует Framer для рендеринга компонентов
2. **Динамическая загрузка**: Модули загружаются с CDN Framer
3. **Встроенные ресурсы**: Большая часть CSS и JS встроена в HTML
4. **Внешние сервисы**: 
   - Cal.com для записи на звонок
   - Framer CDN для модулей

### Размеры файлов

Файлы очень большие (несколько мегабайт каждый), потому что:
- Весь CSS встроен в HTML
- Весь JavaScript встроен в HTML
- Изображения могут быть встроены как base64
- Включены все зависимости Framer

## Рекомендации по работе с проектом

### Для редактирования контента

1. Откройте нужный HTML файл в редакторе
2. Найдите нужный раздел по классам Framer (например, `framer-*`)
3. Внесите изменения в HTML разметку
4. Проверьте результат в браузере

### Для изменения стилей

1. Найдите встроенные `<style>` теги в HTML
2. Или найдите inline стили в атрибутах `style`
3. Внесите изменения напрямую в HTML

### Для изменения функционала

1. Найдите встроенные `<script>` теги в HTML
2. Внесите изменения в JavaScript код
3. Учтите, что Framer модули загружаются динамически

## Запуск проекта

### Вариант 1: Использование скрипта

```bash
./start.sh [PORT]
```

Пример:
```bash
./start.sh 4444
```

### Вариант 2: Прямой запуск Python

```bash
python3 -m http.server 4444
```

### Вариант 3: Использование других серверов

**Node.js (http-server):**
```bash
npx http-server -p 4444
```

**PHP:**
```bash
php -S localhost:4444
```

## Важные замечания

⚠️ **Внимание**: 
- Не удаляйте встроенные скрипты Framer - это сломает сайт
- Изменения в структуре могут нарушить работу динамической загрузки модулей
- Для полноценной работы требуется интернет-соединение (для загрузки модулей с CDN)
